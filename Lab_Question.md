# MCA - 4.6 (OPEN GL)


1. Write a program in OpenGL to draw chess board.

2. Write a program in OpenGL to draw complete graph of N vertices where vertices are on the circle of radius r and center at origin.

3. Write a program in OpenGL to draw a rectangle where thickness and colr of each side should be different.

4. Write a program in OpenGL to draw a filled square of side  and it spin on right mouse button clicking.

5. Write a program in openGL moving circle. When you click right mouse button it move horizontally right to left and on clicking of left mouse button it move vertically from top to bottom.

6. Write a program in openGL to draw a circle where center of the circle should be on the mouse pointer and it should move with mouse pointer.

7. Write a program in openGL rolling circle that roll from left to right and right to left.

8. Write a program in openGL for falling filled squares of colors red green and blue and a square of red should be move left to right and right to left horizontally. When it hit the green or blue falling square then the score will be increment by one.

9. Write a program in openGL for rotating circle at its center. On clicking left mouse button it rotate in clockwise direction and on right mouse button it rotate in anticlockwise.

10. Write an openGL program to draw a line from (x1, y1) to (x2, y2) using simple DDA algorithm.

11. Write an openGL program to draw a line from (x1, y1) to (x2, y2) using Symmetric DDA algorithm.

12. Write an openGL program to draw a line from (x1, y1) to (x2, y2) using Bresenham Line drawing algorithm.

13. Write an openGL program to clip lines against a triangle A(1, 0), B(100, 0), C(50, 50) using Liang-Barsky line clipping algorithm. Enter the ends point of the line is to be clipped from keyboard.

14. Write an openGL program to clip lines against a triangle A(1, 0), B(100, 0), C(50, 50) using Cohen-Sutherland line clipping algorithm. Enter the ends point of the line is to be clipped from keyboard.

15. Write an openGL program to clip lines against a triangle A(1, 0), B(100, 0), C(50, 50) using Midpoint sub-division line clipping algorithm. Enter the ends point of the line is to be clipped from keyboard.

16. Write an openGL program to draw a circle using Midpoint Circle generating algorithm. Enter the center and radius from keyboard.

17. Write an openGL program to draw a circle using direct method Circle generating algorithm. Enter the center and radius from keyboard.

18. Write an openGL program to draw a circle using DDA Circle generating algorithm. Enter the center and radius from keyboard.

19. Write an openGL program to clip line by using Liang-Barsky line clipping algorithm. Enter the ends point of the line is to be clipped from keyboard. Use wxmin = wymin = 10 and wxmax = wymax = 200.

20. Write an openGL program to draw an ellipse using Midpoint Ellipse generating algorithm. Enter the center and length of semi minor and semi major axis from keyboard.

21. Write an openGL program to clip the polygon using Sutherland-Hodgeman polygon clipping algorithm.

22. Write an openGL program to draw a Bezier curve.
